# Isolated bootstrap runtime smoke

The workflow compiles the exact Community candidate, then creates a fresh Linux network namespace with only loopback. The actual binary runs unprivileged with a disposable HOME, no inherited environment, no production config, random temporary recovery credentials and no external egress. It checks the pinned source's bootstrap HTTP listener, JMAP discovery redirect and anonymous session account isolation, followed by graceful shutdown. Bootstrap logs stay private and are removed with the fixture. This is not a configured mail server: no SMTP/IMAP delivery, real account authentication, storage durability, restore or production readiness is established. The separate two-account qualification remains mandatory. Do not install the CI runner artifact or enable recovery on production.
